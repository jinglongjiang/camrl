# 5 人训练到 10/12/20 人泛化：贝叶斯风险注意力验证

日期：2026-09-17。分支：`bayes-risk-generalization-20260917`。

## 先给结论

**坏消息：这次没有证明贝叶斯能改善人群规模泛化，也没有修复 20 人下的崩塌。**

不是只停在训练日志：已对全部 12 个冻结的 IL 模型完成 **7,200 回合**独立部署测试。
训练始终只有 5 人，包含圆形和方形场；10/12/20 人没有进入训练或模型选择。
大人群综合成功率为：基础策略 **35.53%**、CV 风险 **38.40%**、EWMA 风险 **37.33%**、贝叶斯风险 **37.27%**。

贝叶斯相对基础策略有 +1.73 个百分点的点估计，但没有统计上明确的优势，且低于 CV、几乎等于 EWMA。
20 人平稳方形场的贝叶斯成功率只有 **7.33% / 13.33%**，不是“泛化不错”。

**结论限定：当前 GDBN 预测风险引导注意力这一具体改造没有过关。不能推导出所有贝叶斯方法都不能帮助泛化。**
本轮也没有完成完整的 IL+PPO 训练验证：原实验的全组训练资格门失败，PPO 实际更新次数为零。
下述部署结果是另行冻结协议的 **IL-only 终末诊断**，不是通过了原实验，也不是 PPO 的阴性结果。

## 1. 实际比较什么

保持连续动作 `(v, omega)`、10 维机器人历史状态、SetEncoder 192、Actor `[256,256]`、原奖励、原 CV-CEM 教师。
不增加 Cost Critic、安全屏蔽、残差 Actor、Mamba 或 TD3。

四组物理输入、网络容量、初始确定性策略、示范数据、纠错数据、优化预算均相同：

| 组别 | 每个人的风险特征 |
|---|---|
| Base | 全零，原物理状态集合编码 |
| CV | 恒速预测，固定随时间增长的方差 |
| EWMA | 恒速均值，使用速度变化残差在线估计方差 |
| Bayes | 现有 GDBN 递推后验的预测均值和协方差 |

风险通过 `attention_logit += gain * log(0.01 + risk)` 进入注意力。
每组均有相同的一个可学习标量，初始化为零；初始动作经核对与原策略一致。
原 human token 的四个 belief 字段在全部组中归零，避免混合两条信息通道。

风险是 7 条固定机器人探测弧线、8 个未来时刻（2 秒）上的最大高斯圆盘重叠概率。
它不是整段轨迹发生任意碰撞的联合概率。贝叶斯组使用 `trace(covariance)/2` 的各向同性矩近似，
不是完整多模态分布积分，也没有重拟合或重新校准 GDBN。
机器人仍不可见于行人，`B_action=0`；探测动作只改变机器人几何，不虚构人类动作响应。

## 2. 训练预算与隔离

- 三个种子：2407、4807、7207。
- 240 个教师采集回合：234 成功、5 碰撞、1 超时。仅成功轨迹用于 BC，10,322 个样本。
- 五人圆形/方形 × nominal/train_nonstationary 四格各 60 个教师回合。
- 每模型 3,000 次 BC 更新。全部使用同一保存的数据及同一种子下相同的采样索引。
- 一轮 DAgger：每模型 30 回合，共 360 个新布局。学生执行、教师只标注。
- DAgger 有 311 成功、43 碰撞、6 超时；失败状态也保留，共 16,134 个纠错样本。
- 各组共享合并后的 26,456 样本，再进行 3,000 次更新；不保留各组私有额外训练池。
- 开发集：100 个五人布局，分别跑 nominal 和 train_nonstationary；每模型每阶段 200 回合。
- 240 个示范布局、360 个 DAgger 布局、100 个开发布局物理哈希零重叠。
- 最终测试另有 300 个物理布局，和上述全部集合零重叠。

这里的“5 人训练”包含五人方形场，**不再是只训练原五人圆场**。
因此不能把与历史模型的差异全部归因于风险表示；真正归因使用本轮四组之间的同预算比较。

## 3. 原资格门与为什么没有 PPO

事前门槛要求全部 12 个模型分别满足：五人 nominal 成功率至少 90%，train_nonstationary 至少 80%。
最终 DAgger 开发成绩如下，每格为 nominal / train_nonstationary 的成功数，各分母 100：

| 种子 | Base | CV | EWMA | Bayes |
|---|---:|---:|---:|---:|
| 2407 | 90 / 89 | 91 / 90 | 90 / 93 | 93 / 96 |
| 4807 | 92 / 95 | 92 / 91 | **88** / 93 | 94 / 91 |
| 7207 | 90 / 90 | **88** / 92 | 91 / 90 | 91 / 91 |
| 均值 | 90.67 / 91.33 | 90.33 / 91.00 | 89.67 / 92.00 | 92.67 / 92.67 |

Bayes 和 Base 各自三个种子都过门；全组失败来自两个对照模型的 88%。
不能把这件事写成“贝叶斯 Actor 没学会五人导航”。门槛是本次实验规则，不是 PPO 可用性的数学条件。
我们没有事后降低门槛，也没有挑掉那两个种子，原实验保留 `IL_GATE_FAILED`。
原定每模型 20,480 步 PPO 没有运行。

为了不把用户要的泛化问题停在资格门上，另行冻结全部 12 个 DAgger 权重，
在不训练、不选模型的条件下进行下列终末诊断。
这是公开记录的协议扩展，**不得称为原预注册 IL+PPO 实验通过**。

### 大人群综合结果

| 组别 | 成功 / 碰撞 / 超时 | 成功率 | 碰撞率 |

采用种子与布局两层配对 bootstrap，10,000 次；同场景的两个 profile 共用布局重采样。
三组比较各用 98.333% 区间（Bonferroni），单位为成功率百分点：

| 对比 | Bayes 减对照 | 配对区间 | 三个种子的差值 |
|---|---:|---:|---|
| Base | +1.73 | [-2.20, +5.73] | +1.0 / +1.4 / +2.8 |
| CV | -1.13 | [-5.20, +3.00] | -2.2 / 0.0 / -1.2 |
| EWMA | -0.07 | [-4.20, +3.80] | -0.2 / -1.4 / +1.4 |

所有区间都包含零。这不是严格等价证明，也不是贝叶斯无价值的普遍定理。
本次要求相对三个对照均至少 +3pp 且区间下界为正，没有达到。
20 人 nominal 至少 80% 的“绝对泛化可用”目标也远未达到。

## 5. 这次能回答与不能回答什么

可以回答：

1. 当前这条“GDBN 预测风险引导集合注意力”的实现，没有取得可确认的泛化增益。
2. 不带贝叶斯的 CV/EWMA 风险对照不弱；只和 Base 比较会高估贝叶斯归因。
3. 保持五人训练、补入五人方形数据，并不足以让这套学生在二十人场达到良好表现。
4. 贝叶斯五人开发分数略好，不能替代真正的大人群部署验收。

不能回答：所有 Bayesian 方法都不可能泛化；必须训练二十人才有可能成功；
已经否定 Bayesian PPO；已定位崩塌为某一个特定网络或滤波器原因。
本次不是全面枚举贝叶斯模型，也没有测试新的似然、完整分布积分、不同风险聚合或更大的 IL 预算。
不应为了得到“好消息”将这些未测可能性写成已解决。

工程建议：**不把当前风险注意力版本作为已验证的新方法立题，不继续按相同配置长训。**
已有强五人 IL 策略和遮挡稿保留；这条新改造保留为可复现的有限负结果。
