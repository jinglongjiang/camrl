# IL -> Bayesian belief -> PPO 分支：阶段归因报告

日期：2026-09-17。分支：`paper2-stage-audit-20260917`。

## 结论先说

**有一个明确且可达的泛化缺口，但还没有成立的贝叶斯新方法。**

同一个单车环境、同一批布局下，20人方形场教师达到90%/80%，未经PPO的IL学生只有4%/6%。因此，这个高密度部署失败在RL之前就已经存在。PPO三臂没有修复它，但不能再把这次崩塌主要归因于PPO。

这支持下一步研究“如何把教师在复杂人群中的导航能力学进学生”，不支持直接宣称“风险图必然有效”“GDBN必须更换”或“贝叶斯创新已经完成”。

## 1. 本轮实际完成的范围

- 400回合：实际CV单车CEM教师。
- 400回合：round16经等价转换后的原始IL策略，未经过PPO。
- 3,600回合：No-Belief / MAP / FULL，各三个已有PPO训练种子。
- 合计4,400回合；4种配置 × 2种行为条件 × 每格50布局；200个物理布局。
- 所有方法共享布局、行为随机种子、单车动作、奖励、终止条件和真实执行碰撞审计。
- 没有本轮新训练，没有改教师/网络/奖励/GDBN，没有高密度选checkpoint。
- 本轮覆盖的是约定的“教师—IL—PPO阶段定位”矩阵；**混合人数重训、新风险表示和方法创新验收没有执行，不算已完成。**

PPO不是此前只有4–6次更新的smoke：九个检查点均完成20,480环境步、240次Adam更新。它们共享同一个IL起点，只改变belief输入和PPO训练seed。

## 3. 能确定什么，不能确定什么

### A. 有真实、可达的教师—学生差距

20人nominal：教师减IL为 **+86pp，配对95%区间[76,94]**。
同布局中43个教师成功/IL失败，0个IL成功/教师失败。

20人held-out：**+74pp，[62,86]**；不一致对为37:0。

同一单车(v,omega)执行器，所以不是拿全向MPC成绩当天花板。教师也不是数学上界；这些数据只证明该策略能在这些布局取得较高成功率。

### B. 失败在IL阶段已经存在，不是PPO才制造的

20人IL是48/50和47/50碰撞，碰撞回合中位时间均3.25秒，只有各2个在第一秒内碰撞。不是主要因超时，也不是全部由初始重叠构成。

FULL相比IL仅+1.33pp，nominal区间[-3.33,7.33]，held-out区间[-5.33,9.33]。不能说PPO已经修复泛化，也不能说这次是PPO把原本高分的20人策略训坏。

### C. 不只是“人数多”

同样10人，IL nominal圆形84%、方形42%；10人圆形在held-out又掉到44%。人数、几何/目标布局、行为分布都可能参与。圈/方的尺度和目标分布不同，不能把42pp差异写成单变量几何因果效应。

### D. 当前belief没有稳定优势

20人FULL减No-Belief：nominal -1.33pp [-5.33,0.00]；held-out +1.33pp [-4.00,8.68]。
FULL减MAP：分别+2.67pp [-1.33,8.00]和+2.67pp [-6.00,12.00]。

没有严格等价结论，也没有支持FULL稳定获益的结果。当前大缺口是教师与整个学习管线的差距，不是FULL与MAP那几个百分点。

所有区间为5000次布局配对bootstrap；涉及PPO时同时重采样3个seed。它们是逐项探索性区间，未经多重比较校正。IL只有一条训练谱系，不能称作三seed完整IL+RL验证。

## 4. 对原讨论中代码判断的纠正

1. **这条PPO主线的来源教师是CV CEM，不是GDBN CEM。** `teacher_mode='gdbn'`对应归档的pure-IL入口。不能用那行代码证明主线的belief已经通过教师“烧进全部学生”。
2. README中183/200、UNQUALIFIED属于归档GDBN教师，不属于本轮评测的CV教师。
3. 即使教师真的使用belief，也不能推出No-Belief学生必然获得测试时不可观测的信息；“标签来自信念”不等于“信念输入必然冗余”。
4. SetEncoder是排列不变，不是人数分布不变。风险图固定维度也不自动意味着充分统计量。
5. 教师失败不等于任务不可解；学生也可以超过不完美教师，不能说其理论上限被锁死。
6. No-Belief仍有上一动作和route状态，并非完全无历史。FULL只有3个mode概率及entropy，不是完整联合未来分布。

## 6. 下一步如何避免又跑偏

本轮已经完成“同设定教师是否有较高可达成绩”的关卡。**可以继续研究泛化问题，但不能直接宣布新的贝叶斯方法成立。**

下一项最有用的是固定原网络做预算匹配的覆盖对照，再考虑换表示：

- 五人圆形训练，作为原方案；
- 五人多几何布局训练，用于分离几何覆盖与人数扩展；
- 5/10/20混合训练，作为得到更广训练分布的强参考。

三者要匹配并分别报告teacher查询数、环境transition数、optimizer更新、容量。混合训练不再是严格5人训练的零样本对照，不能混写。需使用新测试布局，不能把本轮200个布局再当未见确认集。

如果普通覆盖扩展就修好，创新不能归给新Bayes。若仍有可重复缺口，才有依据研究belief导出的表示/训练机制。简单方法追平不必自动终止一切，但新方法至少要在相同预算下更好，或在相同性能下显著省数据/计算。当前没有这项证据。
