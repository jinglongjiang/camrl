# 五人训练到更大人群：贝叶斯局部交互集合实验

## 状态

正式 9,000 回合已完成。结论是：**做出了能改善泛化的局部集合接口，但没有证明贝叶斯
比简单风险排序带来额外泛化收益，二十人导航也远未达到高成功率目标。**

贝叶斯接口相对原策略的 OOD 成功率提高 17.73 个百分点，校正区间为 [11.60, 23.77]；
但相对 CV 为 -0.47 个百分点，区间 [-5.60, 4.40]。因此不把它包装成贝叶斯论文成功。
这否定的是本次有限模型、接口与预算的增量主张，不是“所有贝叶斯算法不可能泛化”。

## 这次真正改了什么

不是继续给旧 GDBN 调参数。这次新增一个可运行的、因果的贝叶斯局部集合接口：

`五人 IL/DAgger + PPO 策略 -> 预测未来冲突暴露 -> 选择五个局部交互对象 -> 原连续 Actor`

保留连续动作、十维 robot history、SetEncoder、既有 IL 和 PPO。
物理环境仍有实际的 5/10/12/20 人；只是策略输入筛选五人，不删除其他人的物理实体。
所有人的当前观测和历史都参与风险计算。机器人不可见，候选机器人动作只改变机器人轨迹，
不假装会改变行人动力学。没有新增 MPC、Cost Critic、TD3 或 Mamba。

重要限定：本次是已完成 IL+RL 的策略的**部署输入接口改造**，没有声称重新联合训练了
belief-conditioned PPO。三个固定 No-Belief checkpoint 都来自五人 PPO 20,480 步，
原始训练 receipt 记录了 240 次 Adam 更新，不是几次更新的 smoke。

## 为什么这不是上一轮注意力实验的重复

上一轮只给 attention 加风险偏置，max pooling 仍接收所有新增行人。
本次直接控制送入策略的集合大小，检验表示在人数增加时的分布变化是否能被局部集合缓解。
这只是待检验的失效解释，不预先断言它就是崩塌原因。

五人时完全绕过筛选，动作必须与原策略逐位一致。大人群才启用接口。

## 贝叶斯模型与非贝叶斯对照

每人维护最近 W 次可观测速度增量的外积，采用固定零均值高斯增量和 inverse-Wishart
协方差先验。窗口内的后验为：

`nu = nu0 + n; Psi = Psi0 + sum(delta_v delta_v^T)`。

以 CV 为预测均值。第 h 步的位置误差条件协方差为 `c_h Sigma`，其中
`c_h = dt^2 sum(j^2, j=1..h)`。积分掉 Sigma 得到二维 Student-t：

`df = nu - 1; scale = c_h Psi / (nu - 1)`。

Gaussian 对照使用相同历史和后验均值协方差 `c_h Psi/(nu-3)`，仅不积分参数不确定性。
它是匹配一二阶量的 plug-in 对照，不是一个独立调到最优的高斯方法。

对机器人预测轨迹，使用碰撞圆盘的径向半空间概率上界；八步概率乘 dt 后求和，作为
**期望冲突持续时间的上界**。不把它叫“两秒至少碰撞一次的概率”。
先用最近五人产生动作，风险排序后重新计算动作，再做一次固定迭代；没有动作网格搜索。

这套概率解释依赖零均值、局部恒定协方差等模型假设，不是已验证的真实碰撞概率校准，
更不是安全保证。窗口化也不等于对全历史的精确 Bayesian posterior。

五臂共用完全相同的三个已训练 PPO 权重：

1. `all`：所有行人，原策略。
2. `nearest`：最近五人，隔离集合压缩本身的效果。
3. `cv_local`：CV 预测最小净空选五人。
4. `gaussian_local`：自适应高斯冲突暴露选五人。
5. `bayes_local`：Student-t 后验预测冲突暴露选五人。

## 训练域、冻结与检验口径

- 后验参数仅从已有五人 teacher demo 标定，成功回合共 10,322 行。
- 按完整 episode 的 case ID 划分训练/验证；case % 5 == 0 留作验证。
- 搜索 W={4,8,16,32}、nu0={5,10}、先验尺度乘数={0.5,1,2}，共 24 组。
- 只按五人验证集一步预测 NLL 选参数，不按十人或二十人导航成绩选参数。
- 选中 W=4、nu0=5、q=0.0061444686725735664，验证 NLL=-2.993448548329088。
- 三个 PPO seed：2407/4807/7207，checkpoint 固定 attempt0_20480。
- 六场景、nominal/heldout_nonstationary、每格 50 个布局，五臂三 seed，共 9,000 回合。
- 物理 case 从 720000 起，按场景分段；环境 seed 从 280000000 起。
- 300 个独立物理布局在种子、方法和两种行为 profile 间配对，不声称 9,000 个独立布局。
- OOD 汇总排除五人圆形场；分别报告十人方形/圆形、十二人圆形、二十人两种方形场。
- paired bootstrap 10,000 次，同时重采样策略 seed 与场景内布局，两个 profile 保持配对。
- Bayes 对四个对照使用 98.75% 区间，控制四次比较的多重性；所有成功率区间下界大于零
  才通过预设“贝叶斯增量”门。

所有分析口径、数据哈希、代码哈希、checkpoint 哈希已写入运行前 protocol.json。
本次没有重新训练策略；三个 seed 是既有 PPO 训练 seed，不是三次新模型训练。

## 自检与一次明确记录的修正

最初实现使用 max-time 概率。自检发现：所有行人的 df 相同时，Student-t 和 Gaussian
都是同一个标准化净空的单调函数，max-time 排序原则上相同；这无法识别分布形状贡献。
因此停止了初次运行，改为累计冲突暴露量，而不是看结果后调后验参数。

停机前保存了 162 个十回合批次：五人场所有臂，以及十人圆形场原始 `all` 臂；
尚无大人群的改造臂结果。旧目录 `local_risk_generalization_20260917_rank_degenerate`
保留，不用于正式结果。新一轮全部更换物理 case 和 seed，重新运行，不挑选旧结果。

数值检查：inverse-Wishart 40,000 次积分采样得到投影 CDF 0.743145，解析 Student-t
为 0.742698，误差 0.000447。合成的相同协方差案例验证累计量确实可以区分两种分布；
这只是代码/数学可辨识性检查，不当作导航收益证据。

## 创新边界

风险输入、局部行人选择和人群泛化已有近邻工作，不能把这些词本身当作新颖性。
[Anas 等的风险感知导航](https://arxiv.org/abs/2304.03593)已经使用碰撞概率输入并研究
关注多少个移动障碍。[Ng 等的人群行为泛化](https://arxiv.org/abs/2410.12232)则以训练时
行为多样性提升泛化。因此，本次即使有效，也首先只是受控的算法可行性证据；
独立方法贡献还需要全文对比和更强确认，不能直接承诺论文已成立。

## 最终结果

OOD 排除五人场，每臂 1,500 回合。S/C/T 分别为成功、碰撞、超时。

| 接口 | S/C/T | 成功率 | 平均环境回报 |
|---|---:|---:|---:|
| 原策略，全部行人 | 512/986/2 | 34.13% | -0.0617 |
| 最近五人 | 734/752/14 | 48.93% | 0.1395 |
| CV 风险五人 | 785/703/12 | 52.33% | 0.1867 |
| 自适应高斯五人 | 758/729/13 | 50.53% | 0.1643 |
| 贝叶斯预测五人 | 778/709/13 | 51.87% | 0.1829 |

成功率差，Bayes 减对照；同时考虑四次比较的 98.75% 配对区间，单位百分点：

| 对照 | 点估计 | 区间 |
|---|---:|---:|
| 原策略 | +17.73 | [11.60, 23.77] |
| 最近五人 | +2.93 | [-2.93, 8.47] |
| CV 风险五人 | -0.47 | [-5.60, 4.40] |
| 自适应高斯五人 | +1.33 | [-1.87, 4.60] |

贝叶斯增量门：**FAIL**。区间含零不是等价证明；也不能只报它比原策略高了 17.73 分。

## 给用户问题的直接回答

1. **是不是改算法后才能判断？是。** 这次确实改了后验模型、集合构造和策略接口，并做了
   三 seed 配对闭环实验，没有再靠旧 GDBN 的阴性结果推断所有新算法都不行。
2. **能不能只在五人训练改善更大人群？可以，本次已有实测改善。** 所有测试人仍真实存在，
   没有十人/二十人训练。改善主要说明局部集合接口有价值。
3. **证明贝叶斯有独立贡献了吗？没有。** 最近邻已拿到大部分收益，CV 汇总最好；
   posterior predictive 还没有胜过同接口的简单替代。
4. **二十人是否已跑通？没有。** Bayes 在两个 nominal 二十人场分别为 17.33% 和 42.67%，
   不能用十人圆形的 86.67% 掩盖它。
5. **是否因此宣布 IL+Bayes+RL 无路可走？不宣布。** 这轮没有训练一个新 belief-conditioned
   PPO，只验证了冻结 IL/PPO 后的贝叶斯局部集合算法；它不足以否定其他联合训练方法。

交付保留完整实现、强对照、全部原始回合与权重，未来可以复核这个具体改善，
但不把“后验有数学区别”或“比原策略好”偷换成“贝叶斯新方法已经成立”。
