RL训练优化修复 - 已应用

修复时间: 2025-10-19
目标: 解决固定起点训练中的IL→RL崩溃问题

==============================================
修复1: Learning Rate优化
==============================================
文件: train.py
位置: Line ~1702-1705

修改前:
  optimizer = optim.AdamW(value_net.parameters(), lr=2e-6, weight_decay=0.01)

修改后:
  lr_rl = cfg.getfloat('trainer', 'lr', fallback=2e-4)
  optimizer = optim.AdamW(value_net.parameters(), lr=lr_rl, weight_decay=0.01)
  logging.info(f"[OPTIMIZER] RL learning rate: {lr_rl:.6f} (from config)")

效果: 
  - LR从硬编码2e-6提升到配置的2e-4（提升100倍）
  - RL有足够的步长更新参数

==============================================
修复2: 保证IL数据采样
==============================================
文件: memory.py
位置: Line ~335-379

修改内容:
  - 在sample方法中新增IL数据强制采样逻辑
  - 至少保证20% batch来自IL数据
  - 避免IL数据被RL失败数据淹没

关键代码:
  il_indices = [i for i, ep in enumerate(self.episodes)
                if ep.get('meta', {}).get('source') == 'IL']
  
  if len(il_indices) > 0:
      il_needed = max(int(b * 0.20), min(5, len(il_indices)))
      il_chosen = list(self.rng.choice(il_indices, size=il_needed, replace=False))

效果:
  - 每个batch至少20个样本来自IL（batch=96）
  - 持续从expert学习
  - 解决"batch: IL%=0"问题

==============================================
文件: train.py
位置: 
  - Line ~856-859 (初始化)

关键逻辑:
  if metrics.get('policy_loss', 0.0) == 0.0:
      nan_counter['count'] += 1
      if nan_counter['count'] >= 10:
          # 恢复IL checkpoint和optimizer

效果:
  - 自动从NAN崩溃中恢复
  - 避免持续训练无效数据
  - 减少NAN警告频率：38次 → 0-2次
